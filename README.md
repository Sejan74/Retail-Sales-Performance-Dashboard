# Retail Sales Performance Dashboard & Business Insights

## Project Overview
This project features a fully interactive business intelligence dashboard built using Power BI and a retail dataset of 9,800+ transactions, representing over $2.26M in total sales. The goal is to evaluate product category performance, regional sales distribution, and annual sales growth trends to enable data-driven business decisions.

## Tools Used
- **Power BI Desktop** (Data Visualization, DAX, Power Query)
- **Microsoft Excel / CSV** (Data Preparation)

## Key Dashboard Insights
- **Top Performing Category:** Technology generated the highest revenue among all product categories.
- **Regional Breakdown:** West and East regions lead in overall sales volume.
- **Sales Growth Trend:** Annual performance highlights steady revenue scaling from 2016 to 2018.
